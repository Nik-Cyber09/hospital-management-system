# Hospital Management System

Carepoint is a responsive hospital operations demo with patient, doctor, appointment, and billing workflows. It starts with empty records; add a doctor and a patient to begin scheduling visits.

## Start the application

```sh
cd client
npm install
npm run dev
```

For feature details, validation commands, and the important demo/security limitations, see [client/README.md](./client/README.md).

> This repository currently provides a local browser demo, not a production clinical system. Do not store real patient or other sensitive data in it.
